# LibraryIS — автоматизированная информационная система библиотеки

Настольное приложение для Windows (Python 3.12 + PyQt6 + SQLAlchemy). Реализовано по техническому заданию
(отчёт к лабораторной работе №4): 32 функциональных требования (ФТ-1…ФТ-32), три роли, учёт книг,
читателей, выдачи и возврата, заказы поставщикам, отчёты (PDF/Excel/печать), резервные копии, журнал действий.

## Запуск (Windows)

1. Установите Python 3.12 с python.org (при установке поставьте галочку **Add Python to PATH**).
2. Дважды щёлкните **run.bat**. При первом запуске он сам установит нужные библиотеки (1–2 минуты).
3. Войдите под одной из учётных записей:

| Логин | Пароль | Роль | Что доступно |
|---|---|---|---|
| lib | lib123 | Библиотекарь | каталог, читатели, выдача/возврат, справки |
| head | head123 | Заведующий | всё как у библиотекаря + заказы поставщикам, все отчёты, списание книг |
| admin | admin123 | Администратор | пользователи, журнал действий, резервные копии |

Вручную: `pip install -r requirements.txt`, затем `python main.py`.
При первом запуске создаётся база `data/library.db` с демонстрационными данными (42 книги, 24 читателя, история выдач).
Чтобы начать с пустой базы, удалите файл `data/library.db` и в `app/seed.py` оставьте только создание пользователей.

## Соответствие ТЗ

| Требование | Где в программе |
|---|---|

| ФТ-7…ФТ-10 читатели (авто-номер билета, блокировка, карточка, проверка телефона/даты) | вкладка «Читатели» |

| ФТ-21…ФТ-23 поставщики и заказы (статусы, авто-пополнение каталога) | вкладка «Заказы поставщикам» |
| ФТ-24…ФТ-29 справки и отчёты, PDF/Excel/печать | вкладка «Отчёты», карточка читателя |
| ФТ-30 пользователи и роли | Администрирование → Пользователи |
| ФТ-31 резервное копирование | Администрирование → Резервное копирование (+ автокопия раз в сутки, хранение 30 дней) |

Горячие клавиши: **Ctrl+F** — поиск, **Ctrl+N** — новая запись, **F5** — обновить.

## База данных: SQLite или PostgreSQL

По умолчанию используется файловая SQLite (ничего устанавливать не нужно) — удобно для демонстрации.
Для режима «клиент-сервер» из ТЗ: установите PostgreSQL 16, создайте базу `library`, выполните
`pip install psycopg2-binary` и в `config.ini` замените строку `url` на строку PostgreSQL (пример внутри файла).
Таблицы создаются автоматически при первом запуске. Больше в коде ничего менять не нужно.

## Тесты

`python -m pytest` — 26 автоматических тестов: бизнес-правила (ФТ-3, 4, 7, 10, 11, 13–16, 17–19, 23, 31),
блокировка входа, импорт, и «обход» всех окон приложения на ошибки.

## Сборка в .exe (необязательно)

Запустите **build_exe.bat** — в папке `dist\LibraryIS` появится `LibraryIS.exe`, который можно запускать без Python.

## Структура проекта

```
main.py                точка входа
config.ini             настройки (БД, срок выдачи, лимиты)
app/models.py          модель данных (SQLAlchemy)
app/services.py        бизнес-правила и проверки
app/reports.py         отчёты, экспорт в PDF/Excel
app/seed.py            демонстрационные данные
app/ui/                окна и вкладки (PyQt6)
tests/                 автоматические тесты
sample_import.csv      пример файла для импорта каталога
```
